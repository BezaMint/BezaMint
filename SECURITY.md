# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in BezaMint, please report it privately via:

- Email: security@bezamint.dev
- GitHub: Use the "Report a vulnerability" button on the Security tab

We take all security reports seriously and will respond within 48 hours.

### Scope

- Smart contract vulnerabilities (Soroban/Wasm)
- Frontend security issues (XSS, CSRF, etc.)
- API security (authentication, authorization, rate limiting)
- Dependency vulnerabilities

### Out of Scope

- Theoretical attacks without proof of concept
- Social engineering attacks
- Physical attacks
